# RFC 5234 (ABNF)

The IETF standard that defines **Augmented Backus–Naur Form (ABNF)**, a notation
for specifying formal grammars. ABNF is the lingua franca for describing the
syntax of internet protocols and message formats: rules, alternation (`/`),
concatenation, repetition (`*`), optional elements, and terminal values
(including hex like `%x61-7A`).

In [[SPEC-003-realtime-collaborative-editing]] the contract grammars are written
in ABNF after RFC 5234 — the pairing phrase
([[SPEC-003-realtime-collaborative-editing#CON-013]]) and the wire-protocol
frames ([[SPEC-003-realtime-collaborative-editing#CON-014]],
[[SPEC-003-realtime-collaborative-editing#CON-015]],
[[SPEC-003-realtime-collaborative-editing#CON-016]]) — so that each input
language is defined precisely enough to generate a recogniser, per [[LangSec]].
