# PROTO-001: USDD Agent Protocol

This is a vault-local **pointer** to the binding governance protocol that
governs every specification, plan, and artefact in this repository.

The canonical, full text (v1.8.0) lives with the `anuna-dev` skill at
`~/.claude/skills/anuna-dev/references/usdd-agent-protocol.md` and is authored
by [Anuna Research](https://anuna.io) under CC BY 4.0.

It defines, among other things: artefact naming conventions
(`SPEC/IMPL/SCREEN/PROTO` documents; `REQ/NFR/CON/ADR/TEST/OBS/BUG` artefacts),
the wikilink + traceability requirements enforced by `zetl`, the
Vision → Specification → Plan → Code → Feedback workflow, the 15 Constitutional
Principles (including [[LangSec]] input handling and Adversarial Review), the
verification-techniques catalogue, and the convergence/Success-Criteria
definitions.

Specifications in this vault reference it as `[[PROTO-001]]`.
